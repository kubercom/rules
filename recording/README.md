# Как записать видео и аудио для Kubernetes Community Podcast

## Главное правило локальной записи

> **Каждый участник записывает локально только своё видео и только свой микрофон. Голосов остальных участников звонка в файле быть не должно.**

Локально — значит в файл на вашем компьютере. Это правило действует для любой программы записи и любого сервиса звонков:

```text
Ваш микрофон -> в локальную запись
Ваша камера -> в локальную запись

Discord / Zoom / Meet / браузер / системные звуки -> НЕ в запись
```

На монтаже мы собираем отдельные дорожки всех участников. Если в ваш файл попадут чужие голоса, они продублируются: появятся эхо, небольшие задержки и проблемы с синхронизацией. Монтировать такой разговор сложнее, поэтому от каждого нужна чистая локальная дорожка.

Обычная веб-камера, микрофон ноутбука и домашний свет подойдут. Не переживайте, если у вас нет студийного оборудования или OBS: нам важнее интересный разговор, чистый голос и стабильная запись.

## Коротко — TL;DR

1. Наденьте наушники.
2. Поставьте камеру примерно на уровне глаз, а свет — перед собой.
3. Записывайте только свою камеру и свой микрофон.
4. Отключите запись Desktop Audio, Discord, Zoom, Meet и браузера.
5. Сделайте тест на 20–30 секунд прямо во время звонка.
6. Откройте тестовый файл: вас должно быть видно и слышно, остальных — не слышно.
7. По команде ведущего запустите запись и проверьте, что она действительно идёт.
8. После разговора сохраните оригинал до окончания монтажа.

## 1. На что записывать

### macOS

Самый простой вариант — **QuickTime Player**:

```text
Файл -> Новая видеозапись
```

В меню рядом с кнопкой записи выберите свою камеру и микрофон. Качества «Высокое» достаточно. По команде ведущего нажмите кнопку записи. После остановки выберите `Файл -> Сохранить`.

Видеозапись уже содержит звук выбранного микрофона. Если команда попросила отдельный аудиофайл, для него есть команда:

```text
Файл -> Новая аудиозапись
```

Подробнее о выборе устройств — в [инструкции Apple](https://support.apple.com/ru-ru/guide/quicktime-player/qtp356b55534/mac).

Если OBS Studio уже установлен и вы умеете им пользоваться, рекомендуем его. Но устанавливать OBS только ради подкаста не нужно, если QuickTime решает задачу.

### Windows

Самый простой вариант — приложение **«Камера»**: откройте его, разрешите доступ к камере и микрофону, переключитесь в режим видео и сделайте тест. Проверьте, какой микрофон слышен в файле; если приложение не даёт выбрать его, проверьте устройство ввода в настройках звука Windows.

Предпочтительный вариант — **OBS Studio**. В нём удобнее явно выбрать камеру, микрофон, разрешение, частоту кадров и аудиодорожку. Ниже есть пошаговая настройка.

### Linux

Рекомендуем **OBS Studio**: записывайте локально камеру и микрофон по инструкции ниже.

В любой системе проверьте запись одновременно со звонком. Если камера недоступна в двух приложениях сразу, скажите ведущим до начала: вместе выберем рабочий вариант.

## 2. Качество записи

Рекомендуемые параметры, если программа позволяет их выбрать:

```text
Разрешение: 1920x1080
Частота кадров (FPS): 25 или 30
```

60 FPS и 4K для подкаста не нужны: они увеличивают нагрузку и размер файлов.

Если компьютер тормозит, используйте `1280x720` и `25/30 FPS`. Стабильная запись 720p лучше, чем зависающая или повреждённая запись 1080p. Если в QuickTime нет этих настроек, достаточно выбрать «Высокое» качество и проверить тест.

## 3. OBS Studio — как записывать только себя

Названия пунктов могут немного отличаться в зависимости от системы и версии OBS. Программа доступна на [официальном сайте OBS Studio](https://obsproject.com/).

### Шаг 1. Создайте сцену

Сцена — это набор источников, которые попадут в запись. В блоке `Scenes / Сцены` нажмите `+` и назовите новую сцену, например `Podcast Local Recording`.

### Шаг 2. Добавьте камеру

В блоке `Sources / Источники` нажмите:

```text
+ -> Video Capture Device / Устройство захвата видео
```

На Linux источник веб-камеры может называться `Video Capture Device (V4L2)`.

Выберите свою веб-камеру. Если доступны настройки разрешения и FPS, установите `1920x1080` и `25 или 30 FPS`, если камера и компьютер это поддерживают.

Проверьте превью: в кадре должны быть вы. Если изображение не помещается, нажмите на источник правой кнопкой и выберите `Transform -> Fit to Screen / Трансформировать -> Вписать в экран`.

В `Settings -> Video / Настройки -> Видео` выставьте базовое и выходное разрешение `1920x1080`, а общую частоту кадров — `25 или 30`. Для слабого компьютера можно выбрать `1280x720`.

### Шаг 3. Добавьте свой микрофон

В `Sources / Источники` нажмите:

```text
+ -> Audio Input Capture / Захват входного аудиопотока
```

Назовите источник «Мой микрофон» и выберите конкретное устройство вместо `Default / По умолчанию`. Например, `MacBook Microphone`, `USB Microphone`, `AirPods Microphone` или `Headset Microphone` — то, в которое вы будете говорить.

Не добавляйте один микрофон несколько раз. Если камера тоже передаёт звук, отключите её аудио в микшере, оставив только выбранный микрофон.

### Шаг 4. Не записывайте системный звук

> **В локальную запись не должны попадать Desktop Audio, System Audio, Application Audio, Discord, Zoom, Google Meet и браузер.**

В новой сцене достаточно двух источников: камеры и вашего микрофона. Не добавляйте захват звука приложений, аудиовыхода или экрана со звуком. Если такие источники уже есть, удалите их из этой сцены или отключите их звук в микшере.

В `Audio Mixer / Микшер аудио` должен работать только ваш микрофон:

```text
Мой микрофон     ███████
```

`Desktop Audio` должен отсутствовать или быть отключён. Подробнее о видах источников — в [справке OBS](https://obsproject.com/kb/sources-guide).

### Шаг 5. Отключите Desktop Audio

Откройте `Settings -> Audio / Настройки -> Аудио`. В разделе `Global Audio Devices / Глобальные устройства аудио` выберите `Disabled / Отключено` для всех доступных глобальных устройств:

```text
Desktop Audio -> Disabled
Desktop Audio 2 -> Disabled
Mic/Auxiliary Audio -> Disabled
Mic/Auxiliary Audio 2, 3, 4 -> Disabled (если есть)
```

Микрофон при этом останется в записи: вы уже добавили его отдельным источником `Audio Input Capture`. Так он не запишется повторно через глобальный `Mic/Aux`.

Если в вашей системе нет пунктов `Desktop Audio`, пропустите их. Всё равно проверьте источники из шага 4: отключение глобальных устройств не выключает отдельно добавленный захват звука приложений.

### Шаг 6. Проверьте Audio Mixer

Подключите наушники. Попросите другого участника что-нибудь сказать в Discord, Meet или Zoom, а сами помолчите. Индикатор микрофона может показывать фоновый шум, но не должен реагировать на чужую речь.

Затем скажите что-нибудь сами — индикатор должен двигаться:

```text
Я говорю -> OBS показывает мой голос
Другой участник говорит -> OBS не реагирует на его голос
```

Если OBS реагирует на других, проверьте захват системного звука и приложений, а также утечку звука из колонок или наушников в микрофон. После исправления повторите проверку.

### Шаг 7. Используйте наушники

> **Настоятельно рекомендуем наушники на всё время записи.**

Если звонок звучит через колонки ноутбука, микрофон физически слышит чужие голоса через комнату. Они попадут в файл даже при отключённом Desktop Audio.

```text
Голоса остальных участников -> наушники
Ваш голос -> микрофон
```

Если звук из наушников слышен снаружи и попадает в микрофон, уменьшите громкость.

Перед тестом выберите [формат MKV](#14-формат-записи-obs) и проверьте [базовые настройки записи](#15-настройки-obs-без-фанатизма). Для запуска нужна кнопка `Start Recording / Начать запись`.

## 4. Как поставить камеру

- Поставьте камеру примерно на уровне глаз, не сильно снизу.
- Кадрируйте себя примерно по грудь или немного крупнее.
- Оставьте немного свободного пространства над головой.
- Не садитесь слишком далеко от камеры.
- Когда говорите, периодически смотрите в объектив. Постоянно смотреть в камеру не обязательно.
- Ноутбук можно поднять на устойчивую подставку или несколько книг.

Простое правило: **объектив примерно на уровне глаз — уже хорошо**.

## 5. Свет

### Днём

Окно — отличный бесплатный источник света. Сядьте лицом к нему или немного под углом. Не садитесь спиной к яркому окну: камера затемнит лицо.

### Вечером

Подойдёт обычная настольная лампа. Поставьте её перед собой, немного сбоку и чуть выше уровня глаз.

Если свет слишком резкий, направьте лампу в белую стену: отражённый свет будет мягче. Одна удачно поставленная лампа лучше нескольких случайных источников. Не оставляйте единственный яркий свет прямо над головой.

## 6. Звук

> **Для подкаста хороший звук важнее идеальной картинки.**

Если есть отдельный микрофон, используйте его. Если нет, встроенный микрофон ноутбука тоже допустим. Наушники с микрофоном могут звучать лучше него — выберите по тестовой записи.

- Сядьте ближе к микрофону.
- Закройте окна.
- Выключите комнатный вентилятор и кондиционер, если они сильно шумят. Охлаждение компьютера оставьте работать.
- Не стучите по столу и старайтесь не печатать во время записи.
- Уберите телефон подальше от микрофона.
- По возможности выберите комнату с мебелью, шторами и мягкими поверхностями: пустая комната обычно даёт сильное эхо.

## 7. Уровень микрофона

В OBS посмотрите на индикатор своего микрофона в `Audio Mixer / Микшер аудио`. Говорите обычным голосом: сигнал не должен быть слишком тихим или постоянно уходить в красную область.

Ориентир для обычной речи — примерно **−18…−6 dB**. Подгонять каждое слово под цифры не нужно.

```text
Постоянно в красной зоне = слишком громко
Индикатор еле движется = слишком тихо
```

Если слишком громко, уменьшите входной уровень микрофона в настройках звука системы или на самом устройстве. Если тихо — подвиньтесь ближе или немного увеличьте уровень. Проверьте результат на слух в тестовом файле.

## 8. Перед записью обязательно сделайте тест

> **Запишите 20–30 секунд во время звонка и откройте получившийся файл. Одного превью камеры недостаточно.**

1. Запустите локальную запись и скажите несколько обычных фраз.
2. Немного подвигайтесь.
3. Попросите другого участника сказать что-нибудь, пока вы молчите.
4. Остановите запись и дождитесь сохранения. В QuickTime выберите `Файл -> Сохранить`.
5. Откройте файл и посмотрите видео.
6. Послушайте звук в наушниках.

Проверьте:

- камера записалась, изображение не зависает;
- свой голос хорошо слышно, звук не хрипит;
- нет сильного эха;
- **остальные участники не записались**;
- файл нормально открывается.

В OBS найти файл можно через `File -> Show Recordings / Файл -> Показать записи`. Если проигрыватель не открывает MKV, это ещё не значит, что файл повреждён: сделайте MP4-копию [через OBS](#14-формат-записи-obs) и проверьте её, сохранив оригинал.

Если что-то не так, поправьте настройки и повторите тест до начала подкаста. Ведущие помогут, если не получается разобраться.

## 9. Перед началом подкаста

- [ ] Камера выбрана правильно.
- [ ] Микрофон выбран правильно.
- [ ] Desktop Audio и захват звука приложений отключены в OBS, если он используется.
- [ ] Голоса остальных участников не попадают в локальную запись.
- [ ] Наушники подключены, звук звонка идёт в них.
- [ ] Телефон в беззвучном режиме.
- [ ] Уведомления на компьютере отключены.
- [ ] Лишние приложения закрыты.
- [ ] Объектив камеры протёрт.
- [ ] На диске есть свободное место.
- [ ] Ноутбук подключён к питанию.
- [ ] Сделан тест на 20–30 секунд во время звонка.
- [ ] Тест просмотрен и прослушан.
- [ ] По команде ведущего локальная запись запущена.

## 10. Очень важное правило после начала разговора

> **После команды ведущего начать локальную запись убедитесь, что OBS / QuickTime / «Камера» действительно записывает: таймер идёт, доступна кнопка остановки.**

Изображение с камеры само по себе не означает, что запись началась. Иногда поглядывайте на индикатор записи, но постоянно отвлекаться на программу не нужно.

## 11. Если что-то пошло не так

Если запись остановилась, OBS завис, пропал микрофон, закончилась память или место на диске, появилось предупреждение — **сразу скажите ведущим**.

Не продолжайте молча ещё полчаса в надежде, что всё восстановится само. Мы сделаем паузу, проверим настройки и при необходимости начнём новый файл. Уже записанные файлы сохраните.

## 12. После записи

1. После окончания разговора сначала остановите локальную запись.
2. Дождитесь завершения сохранения файла. В QuickTime выберите `Файл -> Сохранить`.
3. Проверьте, что файл существует.
4. Откройте начало и конец записи, убедитесь, что есть изображение и звук.
5. Передайте исходный файл команде способом, о котором договорились с ведущими.
6. Не перекодируйте и не сжимайте видео без необходимости.
7. Сохраните оригинал до окончания монтажа выпуска.

Не нужно самостоятельно улучшать звук, применять шумоподавление, нормализовать громкость, обрезать или конвертировать запись, если команда отдельно об этом не попросила. Для монтажа лучше получить исходный файл.

## 13. Идеальная схема записи

```text
             +--------------------+
Камера ----->|                    |
             |        OBS         |---> local-recording.mkv
Микрофон --->|                    |
             +--------------------+

Discord / Meet / Zoom ----X----> OBS
Discord / Meet / Zoom ---------> Наушники
```

OBS пишет только вашу камеру и ваш микрофон. Звонок нужен для общения, но его звук в локальный файл не попадает.

## 14. Формат записи OBS

Для OBS рекомендуем **MKV**. При неожиданном завершении работы OBS или компьютера уже записанная часть такого файла обычно остаётся доступной. Обычный MP4 при прерывании записи может оказаться непригодным для просмотра. В новых версиях есть устойчивый к сбоям Hybrid MP4; для этой инструкции выбирайте MKV. Различия описаны в [справке OBS о форматах](https://obsproject.com/kb/audio-video-formats-guide).

Если после записи нужен MP4, создайте копию средствами OBS:

```text
File -> Remux Recordings
Файл -> Ремультиплексировать записи
```

Выберите MKV-файл и нажмите кнопку запуска преобразования. Видео и звук переносятся в MP4 без повторного сжатия. **Оригинальный MKV сохраните.** Порядок действий есть в [инструкции OBS по записи](https://obsproject.com/kb/standard-recording-output-guide).

## 15. Настройки OBS без фанатизма

Откройте `Settings -> Output / Настройки -> Вывод`. Для начала достаточно `Output Mode: Simple / Режим вывода: Простой`. В разделе `Recording / Запись`:

```text
Recording Path: папка, которую легко найти, со свободным местом
Recording Format: MKV
Encoder: Hardware encoder, если доступен
```

Аппаратный энкодер помогает компьютеру обрабатывать видео. В списке могут быть Apple VT H264 / HEVC на macOS, NVENC на NVIDIA, Quick Sync на Intel или AMD hardware encoder. Если такой вариант доступен, можно выбрать его. Если нет — оставьте доступный вариант и проверьте тест.

Разбираться в кодеках и битрейтах не требуется. Приоритеты простые:

1. Запись не тормозит.
2. Файл не повреждается.
3. Лицо видно.
4. Голос хорошо слышно.
